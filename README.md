# Highway Havoc

A simple 2D top-down arcade racing game built using modern C++, OpenGL, GLFW, GL2D and CMake.

This project is being developed from scratch while following good software engineering practices, including small incremental commits, clean project organization and version-controlled milestones.

---

## Features (Planned)

- Player-controlled car
- Smooth movement
- Endless highway
- Enemy traffic
- Collision system
- Health system
- Score tracking
- Main menu
- Sound effects
- Production build
- itch.io release

---

## Technologies

- C++17
- OpenGL
- GLFW
- GLAD
- GLM
- GL2D
- ImGui
- CMake
